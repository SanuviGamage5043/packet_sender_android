Detailed Breakdown:

A. ESP32 Communication & Discovery
UDP Broadcast Support (broadcastEnabled = true):
ESP32 devices on local networks are rarely static. Enabling UDP broadcast allows sending 255.255.255.255 discovery pings without knowing the ESP32's assigned DHCP IP upfront.
ESP32 Subnet Device Scanner:
A "Scan for ESP32" tool that sweeps the local network or listens for mDNS (esp32.local, wled.local) to auto-populate the Host field with discovered device IPs.
Persistent TCP & WebSocket Mode:
Currently, TCP sockets close immediately after sending. Controlling LED effects and sliders requires keeping a socket or WebSocket (ws://esp32/ws) continuously open to avoid repeated 3-way handshakes.
Dual Response Inspector (ASCII + Hex Dump):
Microcontrollers frequently send back binary status flags, frame ACKs (e.g. 0x06), or binary telemetry. The response viewer should display both ASCII and a formatted Hex Dump (Hex bytes + printable ASCII) without byte corruption.


B. LED Panel & Matrix Tools (High Priority)
Interactive Color Picker & RGB Streamer:
A color wheel and brightness slider that immediately constructs and sends payloads in popular ESP32 formats:
Raw 3-byte RGB: [0xFF, 0x80, 0x00]
Hex string: #FF8000 or FF8000
JSON command: {"r":255, "g":128, "b":0, "bri":200}
Custom delimiter: SET 255,128,0\n
Interactive Matrix Canvas (8x8 / 16x16 / 32x32 / 64x32):
A visual grid where you tap/draw pixels.
Sends real-time coordinate packets (x, y, r, g, b) or full-frame bitmap buffer to drive WS2812 matrices or HUB75 panels.
Supports both Row-Major and Serpentine (Zig-Zag) LED strip wiring layouts.
Scrolling Text Marquee Generator:
Type a text string (e.g., "HELLO ESP32"), pick text color, background color, and scroll speed — PacketFlow formats it into the appropriate command packet for your panel firmware.
WLED & Art-Net DMX Presets:
Native presets for WLED real-time streaming (WARLS / DRGB on UDP port 21324) and Art-Net (UDP port 6454).



C. Automation & Testing Tools
Continuous Packet Streamer (FPS / Keep-Alive):
Stream packets at specified intervals (e.g., every 33ms for ~30 FPS animation testing, 100ms, or 1000ms for keep-alive pings) with an active FPS counter and packet statistics.
Macro & Sequence Runner:
Chain multiple commands with customizable delays (e.g., Step 1: Init ESP32 -> wait 200ms -> Step 2: Set Brightness -> wait 100ms -> Step 3: Trigger Animation).
Packet Framing & Checksum Helper:
Microcontroller protocols often require framing bytes and checksums: [Header 0xAA] [Length] [Command ID] [Payload] [CRC/Checksum] [Footer 0x55].
Automatically calculates CRC8, CRC16, or XOR checksums so you don't have to manually calculate them.

Supported Checksum Algorithms:
